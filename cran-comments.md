## Notes for the reviewer

* Move generation, 'FEN' and 'PGN' parsing and the 'UCI' client are
  implemented from the public specifications and verified against the published
  perft reference counts. No code or data is derived from an existing chess
  library.
* The bundled ECO book and puzzle set in `inst/extdata` are generated by the
  scripts in `data-raw/`, which replay and validate every line through the
  package's own move generator.
* All optional dependencies (processx, shiny, bslib, shinyWidgets, plotly,
  withr) are in Suggests and guarded with `requireNamespace()`.
* The 'UCI' example runs only when 'processx' and an external `stockfish`
  binary are available; the Shiny example runs only in interactive sessions.
* Deep perft counts, long simulations and app tests are skipped on CRAN to keep
  the check time short.
