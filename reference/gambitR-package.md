# gambitR: Chess Engine, Analysis and Interactive Study Tools

A self-contained chess toolkit in native R. Provides legal move
generation, game-state tracking and 'FEN'/'PGN' parsing, position
evaluation and a minimax search with alpha-beta pruning for play and
simulation, batch tournament simulation between strategies, an opening
explorer and puzzle trainer, and an interactive 'Shiny' application for
playing, analysing, studying and annotating games. An optional 'UCI'
engine hook enables deeper analysis when an external engine such as
'Stockfish' is available.
